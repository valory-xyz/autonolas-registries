# stale

Contracts that were written and reviewed but **never deployed to any chain**.

They are kept here rather than deleted so the work is not lost and can be picked up again. They are not
part of the active deployment set, and `docs/configuration.json` lists no address for them.

Distinct from `deprecated/`, which holds contracts that *were* deployed and have since been replaced —
those keep a source of record for the code still live on-chain.
